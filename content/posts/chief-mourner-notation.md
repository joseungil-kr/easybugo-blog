## 기본 순서

전통적으로는 다음 순서를 따릅니다.

1. 배우자
2. 자녀 (보통 장남 → 차남 → 장녀 → 차녀 순, 성별보다 출생 순)
3. 자녀의 배우자(며느리, 사위)
4. 그 외 친인척(손자녀 등)

최근에는 순서를 엄격히 따지기보다 실제로 상을 치르는 가족 구성에 맞게 자연스럽게 적는 경우도 많습니다.

## 며느리·사위 표기

며느리와 사위도 상주 명단에 함께 적는 경우가 흔해졌습니다.

```
상주 : 배우자 OOO
        아들 OOO · 며느리 OOO
        딸 OOO · 사위 OOO
```

관계를 명확히 적어주면 받는 분이 헷갈리지 않습니다.

## 표기 예시

```
빈소  OO장례식장 3호실
발인  8월 24일(월) 오전 7시

상주 : 배우자 OOO
        아들 OOO, 딸 OOO
```
