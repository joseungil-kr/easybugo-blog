## 기본형

```
[부고]

OOO 님께서 2026년 8월 22일 별세하셨습니다.

가족장으로 조용히 모시고자 하며,
조문과 조의는 정중히 사양하겠습니다.
마음만 감사히 받겠습니다.

- 상주 OOO 올림
```

## 조의금까지 사양할 때

```
가족의 뜻에 따라 가족장으로 진행하며
조문과 화환, 조의금은 정중히 사양합니다.
따뜻한 마음만으로 감사히 받겠습니다.
```
