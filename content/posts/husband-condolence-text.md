## 부상(남편상)이란

부상(夫喪)은 남편이 돌아가신 것을 뜻합니다. 아내가 상주로서 남편의 부고를 알릴 때 쓰는 표현이며, 최근에는 한자어 그대로보다 '남편상'이라는 쉬운 말로 더 많이 씁니다.

## 상주에게 보내는 위로문자

### 기본형

```
남편분 소식을 듣고 너무 놀랐습니다.
삼가 고인의 명복을 빕니다.
지금은 무슨 말씀을 드려도 위로가 안 되시겠지만,
마음만이라도 함께하겠습니다.
```

### 문자용 짧은 버전

```
소식 듣고 마음이 무겁습니다.
삼가 조의를 표합니다.
```

### 가까운 사이일 때

```
소식 듣고 너무 놀라서 뭐라고 해야 할지 모르겠어.
지금은 아무 말도 위로가 안 되겠지만, 옆에 있을게.
힘들면 언제든 연락해.
```

## 조의금 얼마나

조의금은 돌아가신 분과의 관계가 아니라 "나와 상주의 관계"를 기준으로 정합니다. 직장 동료·지인이면 5만 원, 친한 친구나 가까운 동료면 10만 원이 무난합니다. 배우자상은 부모상과 함께 가장 큰 슬픔으로 여겨지는 만큼, 평소 가까웠다면 형편에 맞게 조금 더 하는 경우도 많습니다. 정확한 관계별 기준은 <a class="action-link" href="/posts/condolence-money-by-relation/">조의금 액수 관계별 정리</a>를 참고하세요.
