## 관계별 가격대

정해진 기준은 없지만 통상 다음을 참고합니다.

| 관계 | 가격대 |
|---|---|
| 지인·직장 동료 | 5만~7만 원 |
| 친한 사이·거래처 | 8만~12만 원 |
| 회사 대표 명의, 중요 거래처 | 12만~20만 원 이상 |

## 3단 vs 5단 화환 차이

단수는 화환의 층 수입니다. 5단이 더 크고 격식 있어 보이지만 가격도 높고, 빈소 공간이 좁으면 오히려 부담이 될 수 있습니다. 최근에는 실용적인 이유로 3단을 많이 선택합니다.

## 리본 문구 쓰는 법

기본 문구는 다음 중 하나를 씁니다.

```
삼가 고인의 명복을 빕니다
근조
부의
```

## 리본에 회사명 쓰는 법

보내는 주체를 명확히 하려면 리본 양쪽에 각각 문구와 발신자를 적습니다.

```
(좌측 리본) 삼가 고인의 명복을 빕니다
(우측 리본) ○○주식회사 대표이사 OOO
```

개인이라면 소속과 이름을 함께 적으면 됩니다.

```
(우측 리본) ○○부서 OOO 올림
```

## 화환은 어떻게 보내나

대부분 장례식장 근처 화원이나 온라인 화환 서비스를 통해 주문하면, 빈소로 바로 배송·설치됩니다. 부고장을 받았다면 부고장에 안내된 화환 예약 링크를 이용하는 것이 가장 빠릅니다.
