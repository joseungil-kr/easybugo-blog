## 기본형 부고 문자 양식

가장 무난하게 쓸 수 있는 기본 양식입니다. 대괄호 부분만 바꿔서 그대로 쓰시면 됩니다.

```
[부고]

OOO 님께서 2026년 8월 22일 별세하셨습니다.

빈소  OO장례식장 3호실
발인  8월 24일(월) 오전 7시

삼가 조의를 표해 주시면 감사하겠습니다.

- 상주 OOO 올림
```

## 짧은 문자용 부고 양식

글자 수를 아껴야 하거나 SMS로 짧게 보낼 때는 이렇게 줄여서 씁니다.

```
[부고] OOO 님 별세.
빈소 OO장례식장, 발인 8월 24일(월) 오전 7시.
- OOO 올림
```

## 모바일 부고장 링크를 함께 보내는 경우

요즘은 문자 안에 지도, 연락처, 부의금 계좌까지 다 넣어야 해서 텍스트만으로는 정보가 부족한 경우가 많습니다. 이럴 때는 위 문구 끝에 모바일 부고장 링크 한 줄만 추가하면, 받는 분이 눌러서 빈소 위치·발인 일시·조문 안내까지 한 번에 확인할 수 있습니다.

## 부고 문자 쓸 때 빠뜨리면 안 되는 5가지

1. 고인 성함
2. 별세 일시
3. 발인 일시
4. 빈소 위치(장례식장 이름, 호실)
5. 상주 성함

이 다섯 가지만 들어가면 부고 문자로서 부족함이 없습니다. 문구를 다듬을 시간이 없다면 위 기본형을 그대로 복사해서 대괄호만 채워 넣으세요.
