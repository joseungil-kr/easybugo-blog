## 앞면에는 부의 문구를 적습니다

분당차병원 장례식장의 장례상식 안내는 초상 봉투에 '부의(賻儀)'를 쓰는 것이 가장 일반적이며, '근조(謹弔)', '조의(弔儀)', '전의(奠儀)' 등도 사용한다고 설명합니다. 봉투에 문구가 이미 인쇄되어 있다면 같은 문구를 다시 적을 필요는 없습니다.

출처: <a href="https://bundang.chamc.co.kr/funeral/ProcInfo/commonSense.aspx">분당차병원 장례식장 — 장례상식·조의금</a>.

### 앞면 작성 예시

아래는 앞면 중앙에 문구를 놓는 간단한 텍스트 예시입니다.

```text
┌────────────────┐
│                │
│       賻儀     │
│      (부의)    │
│                │
└────────────────┘
          앞면
```

## 뒷면에는 이름을 어디에 쓰나요?

충청 장례길잡이의 부의금 봉투 작성 안내는 이름과 소속을 뒷면에 적고, 이름은 왼쪽 아래, 소속은 이름 위쪽 또는 오른쪽에 두는 예시를 제시합니다. 이는 해당 장례 안내 자료의 예시 배치이며 법적 규정이나 모든 상가에 강제되는 단일 규칙은 아닙니다.

출처: <a href="https://doeum.kr/magazine/blog/%EC%9E%A5%EB%A1%80_%EC%98%88%EC%A0%88/condolence-money-envelope-writing-guide">충청 장례길잡이 — 부의금 봉투 표기 안내</a>.

### 뒷면 작성 예시

아래 도식은 이름을 왼쪽 아래에, 소속을 이름 오른쪽에 표시하는 한 가지 예시입니다. 화면 글꼴에 따라 실제 위치가 달라 보일 수 있으므로 배치의 개념을 확인하는 용도로 사용하세요.

```text
┌────────────────┐
│                │
│                │
│                │
│ 홍   ○○회사    │
│ 길             │
│ 동             │
└────────────────┘
          뒷면
```

- 개인 이름만으로 전달자를 알 수 있으면 이름만 적어도 됩니다.
- 회사·모임을 통해 전달한다면 소속을 함께 적으면 동명이인을 구분하는 데 도움이 됩니다.
- 가로쓰기 봉투나 미리 인쇄된 작성 칸이 있다면 해당 형식에 맞춰 적으세요.

## 전달 전 확인할 것

- 앞면에 부의 문구가 이미 인쇄되어 있는지
- 뒷면 이름이 실제 전달자와 일치하는지
- 소속이나 단체명이 필요한 상황인지
- 여러 사람이 함께 전달한다면 이름이 누구를 가리키는지 명확한지

이 글의 도식은 작성 위치를 이해하기 위한 편집 예시입니다. 장례식장 접수처에서 별도 작성 안내를 제공하면 해당 안내를 우선하세요.
