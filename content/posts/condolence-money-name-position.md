## 이름 적는 위치

**봉투 뒷면 왼쪽 아래**에 세로로 적는 것이 일반적입니다.

```
(뒷면)



              OOO
```

소속이 있다면 이름 위에 작게 소속을, 그 아래 이름을 적습니다.

```
              ○○부서
              OOO
```

## 앞면은 문구만

앞면에는 "부의", "근조" 같은 문구만 적고 이름은 적지 않습니다. 봉투 전체 작성법은 <a class="action-link" href="/posts/condolence-money-envelope-guide/">부의봉투 쓰는 법</a>을 참고하세요.
