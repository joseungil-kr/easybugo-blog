## 자매상이란

자매상(姊妹喪)은 여자 형제 중 한 명이 세상을 떠난 것을 뜻합니다. [형제상]과 구분 없이 통일해서 쓰는 경우도 많고, 여자 형제임을 명확히 하고 싶을 때 [자매상]을 씁니다.

## 상주에게 보내는 위로문자

### 기본형

```
소식을 듣고 마음이 많이 무겁습니다.
삼가 고인의 명복을 빕니다.
자매를 먼저 보낸 슬픔이 얼마나 크실지 짐작이 갑니다.
```

### 문자용 짧은 버전

```
소식 듣고 마음이 무겁습니다.
삼가 조의를 표합니다.
```

### 가까운 사이일 때

```
소식 듣고 너무 놀랐어. 뭐라 위로할 말이 없다.
힘들겠지만 잘 버텨내길 바라. 필요한 거 있으면 연락해.
```

## 조의금 얼마나

조의금은 돌아가신 분과의 관계가 아니라 "나와 상주의 관계"를 기준으로 정합니다. 직장 동료·지인이면 5만 원, 친한 친구나 가까운 동료면 10만 원이 무난합니다. 형제자매상도 직계가족상에 준하게 여기는 경우가 많아, 평소 가까운 사이라면 형편에 맞게 조금 더 하기도 합니다. 정확한 관계별 기준은 <a class="action-link" href="/posts/condolence-money-by-relation/">조의금 액수 관계별 정리</a>를 참고하세요.
