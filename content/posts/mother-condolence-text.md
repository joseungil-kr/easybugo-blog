## 모친상이란

모친상(母親喪)은 어머니가 돌아가신 것을 뜻합니다. 상주인 자녀가 어머니의 부고를 알릴 때 [모친상]이라는 표현을 쓰며, 자녀의 성별과 관계없이 동일하게 씁니다.

## 상주에게 보내는 위로문자

### 기본형

```
모친상을 당하셨다는 소식을 들었습니다.
삼가 고인의 명복을 빕니다.
갑작스러운 소식에 얼마나 마음이 아프실지 짐작이 갑니다.
```

### 문자용 짧은 버전

```
모친상 소식에 마음이 무겁습니다.
삼가 조의를 표합니다.
```

### 가까운 사이일 때

```
어머님 소식 듣고 마음이 많이 아팠어.
힘든 시간이겠지만 몸 잘 챙기고, 필요한 거 있으면 편하게 연락해.
```

## 조의금 얼마나

조의금은 돌아가신 분과의 관계보다 "나와 상주의 관계"가 기준입니다. 직장 동료·지인이면 5만 원, 친한 친구나 가까운 동료면 10만 원이 무난합니다. 부모상은 슬픔이 큰 만큼 평소 친분이 있었다면 형편에 맞게 조금 더 하는 경우도 흔합니다. 정확한 관계별 기준은 <a class="action-link" href="/posts/condolence-money-by-relation/">조의금 액수 관계별 정리</a>를 참고하세요.
