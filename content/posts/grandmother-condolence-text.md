## 조모상이란

조모상(祖母喪)은 할머니가 돌아가신 것을 뜻합니다. 손자·손녀가 상주 역할을 하며 부고를 알릴 때 쓰는 표현으로, 손자·손녀의 성별과 무관하게 동일하게 씁니다.

## 상주에게 보내는 위로문자

### 기본형

```
할머님 소식을 듣고 마음이 무겁습니다.
삼가 고인의 명복을 빕니다.
가족 모두 힘든 시간 잘 보내시길 바랍니다.
```

### 문자용 짧은 버전

```
할머님 소식에 마음이 무겁습니다.
삼가 조의를 표합니다.
```

### 가까운 사이일 때

```
할머니 소식 들었어. 마음이 많이 아프겠다.
힘든 시간이겠지만 잘 버텨내길 바라. 필요하면 연락해.
```

## 조의금 얼마나

조의금은 돌아가신 분과의 관계가 아니라 "나와 상주의 관계"를 기준으로 정합니다. 조부모상은 직장 동료·지인 사이라면 굳이 안 해도 결례가 아닌 경우가 많고, 가까운 사이라면 3만~5만 원 정도가 무난한 선입니다. 정확한 관계별 기준은 <a class="action-link" href="/posts/condolence-money-by-relation/">조의금 액수 관계별 정리</a>를 참고하세요.
