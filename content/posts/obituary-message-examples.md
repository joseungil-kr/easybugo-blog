## 일반 예시

```
[부고]

OOO 님께서 2026년 8월 22일 별세하셨습니다.

빈소  OO장례식장 3호실
발인  8월 24일(월) 오전 7시

- 상주 OOO 올림
```

## 회사·거래처용 예시

```
삼가 부고를 전해드립니다.
OOO(직위) 님의 부친께서 별세하셨습니다.

빈소  OO장례식장 3호실
발인  8월 24일(월) 오전 7시

바쁘신 가운데 참고하시어 조의를 베풀어 주시면 감사하겠습니다.
```

## 친구·지인용 짧은 예시

```
[부고] OOO 님 별세.
빈소 OO장례식장, 발인 8월 24일(월) 오전 7시.
```
