## 부친상이란

부친상(父親喪)은 아버지가 돌아가신 것을 뜻합니다. 상주인 자녀가 아버지의 부고를 알릴 때 [부친상]이라는 표현을 쓰며, 자녀의 성별과 관계없이 동일하게 씁니다.

## 상주에게 보내는 위로문자

### 기본형

```
부친상을 당하셨다는 소식을 들었습니다.
삼가 고인의 명복을 빕니다.
힘든 시간이시겠지만 마음 굳게 잡으시기 바랍니다.
```

### 문자용 짧은 버전

```
부친상 소식에 마음이 무겁습니다.
삼가 조의를 표합니다.
```

### 가까운 사이일 때

```
아버님 소식 듣고 많이 놀랐어.
뭐라 위로할 말이 없다. 힘들겠지만 잘 버텨내길 바라.
필요한 거 있으면 언제든 연락해.
```

## 조의금 얼마나

조의금은 돌아가신 분과의 관계가 아니라 "나와 상주의 관계"를 기준으로 정합니다. 직장 동료·지인이면 5만 원, 친한 친구나 가까운 동료면 10만 원이 무난합니다. 부모상은 인생에서 가장 큰 슬픔으로 여겨지는 만큼, 평소 친분이 있었다면 형편에 맞게 조금 더 하는 경우도 많습니다. 정확한 관계별 기준은 <a class="action-link" href="/posts/condolence-money-by-relation/">조의금 액수 관계별 정리</a>를 참고하세요.
