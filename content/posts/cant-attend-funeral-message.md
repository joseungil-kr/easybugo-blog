## 기본 예시

```
삼가 조의를 표합니다.
사정이 있어 직접 찾아뵙지 못해 죄송합니다.
마음만이라도 함께하겠습니다.
```

## 거리가 멀 때

```
멀리 있어 직접 찾아뵙지 못하는 점
너그러이 양해 부탁드립니다.
삼가 고인의 명복을 빕니다.
```

## 조의금을 계좌로 보낼 때

```
직접 찾아뵙지 못해 죄송한 마음에
조의금을 계좌로 보내드립니다.
삼가 고인의 명복을 빕니다.
```

## 나중에라도 인사드리고 싶을 때

```
장례 중에는 찾아뵙지 못했습니다.
시간 내서 따로 인사드리러 가겠습니다.
```
