## 상사 본인상을 팀에 알릴 때

```
[부고]

OOO 팀장님의 부친(모친)께서
2026년 8월 22일 별세하셨습니다.

빈소  OO장례식장 3호실
발인  8월 24일(월) 오전 7시

바쁘신 가운데 참고하시어 조의를 베풀어 주시면 감사하겠습니다.
```

## 본인이 상을 당해 상사에게 알릴 때

```
팀장님, 갑작스러운 연락 드려 죄송합니다.
저희 아버지(어머니)께서 오늘 별세하셨습니다.
장례는 OO장례식장에서 진행하며, 발인은 8월 24일(월)입니다.
업무는 OOO 님께 인수인계하였습니다.
```
