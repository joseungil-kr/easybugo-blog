## 고모상이란

고모상(姑母喪)은 아버지의 여자 형제, 즉 고모가 돌아가신 것을 뜻합니다. 어머니의 여자 형제인 이모와 구분해서 쓰는 표현입니다.

## 상주에게 보내는 위로문자

### 기본형

```
고모님 소식을 듣고 마음이 무겁습니다.
삼가 고인의 명복을 빕니다.
가족분들 모두 힘든 시간 잘 보내시길 바랍니다.
```

### 문자용 짧은 버전

```
고모님 소식에 마음이 무겁습니다.
삼가 조의를 표합니다.
```

### 가까운 사이일 때

```
고모님 소식 들었어. 마음이 많이 아프겠다.
힘든 시간이겠지만 잘 버텨내길 바라.
```

## 조의금 얼마나

조의금은 돌아가신 분과의 관계가 아니라 "나와 상주의 관계"를 기준으로 정합니다. 고모상처럼 방계 친척상은 직장 동료·지인 사이라면 부고를 받았더라도 조의금을 꼭 하지 않아도 결례가 아닙니다. 가까운 사이라면 3만~5만 원 정도가 무난한 선입니다. 정확한 관계별 기준은 <a class="action-link" href="/posts/condolence-money-by-relation/">조의금 액수 관계별 정리</a>를 참고하세요.
