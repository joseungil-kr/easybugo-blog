## 시부상(시아버지상)이란

시부상(媤父喪)은 남편의 아버지, 즉 시아버지가 돌아가신 것을 뜻하며, 며느리 입장에서 쓰는 표현입니다. 실제 부고 제목에는 보통 [부친상]을 그대로 쓰지만, 관계를 설명할 때는 '시부상' 또는 '시아버지상'이라는 표현을 씁니다.

## 상주에게 보내는 위로문자

### 기본형

```
시아버님 소식을 듣고 마음이 무겁습니다.
삼가 고인의 명복을 빕니다.
힘든 시간이시겠지만 몸 잘 챙기시기 바랍니다.
```

### 문자용 짧은 버전

```
시아버님 소식에 마음이 무겁습니다.
삼가 조의를 표합니다.
```

### 가까운 사이일 때

```
시아버님 소식 들었어. 많이 힘들지.
남편분도 챙기고, 필요하면 언제든 연락해.
```

## 조의금 얼마나

조의금은 돌아가신 분과의 관계가 아니라 "나와 상주의 관계"를 기준으로 정합니다. 직장 동료·지인이면 5만 원, 친한 친구나 가까운 동료면 10만 원이 무난합니다. 배우자의 부모상도 직계가족상에 준하게 여기는 경우가 많아, 평소 가까운 사이라면 형편에 맞게 조금 더 하기도 합니다. 정확한 관계별 기준은 <a class="action-link" href="/posts/condolence-money-by-relation/">조의금 액수 관계별 정리</a>를 참고하세요.
