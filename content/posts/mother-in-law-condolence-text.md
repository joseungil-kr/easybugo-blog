## 빙모상(장모상)이란

빙모상(聘母喪)은 아내의 어머니, 즉 장모가 돌아가신 것을 뜻합니다. 사위가 처가 부고를 알릴 때 쓰는 관용적 표현이며, 최근에는 이해하기 쉽게 '장모상'이라고도 많이 씁니다.

## 상주에게 보내는 위로문자

### 기본형

```
장모님 소식을 듣고 마음이 무겁습니다.
삼가 고인의 명복을 빕니다.
처가 어른들 모두 얼마나 상심이 크실지 걱정됩니다.
```

### 문자용 짧은 버전

```
장모님 소식에 마음이 무겁습니다.
삼가 조의를 표합니다.
```

### 가까운 사이일 때

```
장모님 소식 들었어. 많이 힘들지.
아내분도 잘 챙기고, 필요하면 언제든 연락해.
```

## 조의금 얼마나

조의금은 돌아가신 분과의 관계가 아니라 "나와 상주의 관계"를 기준으로 정합니다. 직장 동료·지인이면 5만 원, 친한 친구나 가까운 동료면 10만 원이 무난합니다. 배우자의 부모상도 직계가족상에 준하게 여기는 경우가 많아, 평소 가까운 사이라면 형편에 맞게 조금 더 하기도 합니다. 정확한 관계별 기준은 <a class="action-link" href="/posts/condolence-money-by-relation/">조의금 액수 관계별 정리</a>를 참고하세요.
